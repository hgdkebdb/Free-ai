# Настройка Info.plist

Для корректной работы приложения с датчиками движения (магнитометром)
**обязательно** добавьте в `Info.plist` следующий ключ:

```xml
<key>NSMotionUsageDescription</key>
<string>Приложению нужен доступ к датчикам движения для определения уровня магнитного поля и поиска металла или проводки в стенах.</string>
```

## Пояснение

- Ключ `NSMotionUsageDescription` обязателен для приложений, использующих
  `CMMotionManager` и магнитометр устройства.
- Без этого ключа iOS не предоставит приложению доступ к данным датчика,
  и при попытке вызова `startMagnetometerUpdates(...)` приложение
  будет аварийно завершено с сообщением об отсутствии описания
  использования датчиков движения.
- Текст описания можно адаптировать под язык интерфейса приложения,
  главное — он должен объяснять пользователю, зачем нужен доступ.

## Минимальные требования

- iOS 14.0+ (для удобной работы со SwiftUI и `@StateObject`).
- Физическое iOS-устройство с магнитометром
  (симулятор данные магнитометра не предоставляет).

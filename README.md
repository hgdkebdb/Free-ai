# Metal & Wire Detector

iOS-приложение на SwiftUI для обнаружения металлических объектов и электропроводки
с помощью встроенного магнитометра устройства (CoreMotion).

## Принцип работы

- Приложение получает данные магнитометра через `CMMotionManager`.
- Сила магнитного поля рассчитывается по формуле модуля вектора:
  `B = sqrt(x² + y² + z²)` (в микротесла, μT).
- Нормальный фон Земли составляет 30–60 μT.
- Превышение порога 100 μT сигнализирует о наличии металла или электромагнитного излучения.

## Диапазоны индикации

| Значение, μT | Статус                                       | Цвет     |
|--------------|----------------------------------------------|----------|
| < 70         | Стена чиста / Металл не обнаружен            | Зелёный  |
| 70 – 120     | Подозрение на металл/проводку                | Жёлтый   |
| > 120        | ВНИМАНИЕ! Обнаружен металл или кабель!       | Красный  |

## Калибровка

Кнопка **«Калибровка»** запоминает текущее значение магнитного поля как фоновое
и вычитает его из последующих замеров — это удобно, чтобы «обнулить» естественный
фон Земли в конкретной точке.

## Тактильная отдача

При превышении значения **100 μT** срабатывает `UIImpactFeedbackGenerator`
(стиль `.heavy`) — телефон вибрирует, сигнализируя о находке.
Чтобы не «трясти» постоянно, вибрация ограничена частотой ~3 раза в секунду.

## Структура проекта

- `MetalWireDetectorApp.swift` — точка входа (`@main`).
- `MagnetometerManager.swift` — работа с CoreMotion: чтение датчика,
  калибровка, расчёт силы поля, тактильная отдача.
- `ContentView.swift` — пользовательский интерфейс на SwiftUI: круговой
  индикатор, текстовый статус, кнопка калибровки.

## Info.plist

Для доступа к датчикам движения в `Info.plist` **обязательно** нужно добавить
ключ с описанием цели использования датчика:

```xml
<key>NSMotionUsageDescription</key>
<string>Приложению необходим доступ к датчикам движения для измерения магнитного поля и обнаружения металла.</string>
```

Без этой строки iOS не предоставит приложению доступ к магнитометру,
и пользователь не увидит запрос разрешения.

## Требования

- iOS 15.0+
- Устройство с магнитометром (большинство iPhone). На Симуляторе
  магнитометр недоступен — приложение покажет соответствующее сообщение.

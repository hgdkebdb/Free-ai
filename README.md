# Metal & Wire Detector

iOS-приложение для обнаружения металла и электропроводки в стенах с помощью встроенного в iPhone магнитометра.

## Стек технологий

- **Язык:** Swift 5
- **UI:** SwiftUI
- **Датчики:** CoreMotion (`CMMotionManager` → `magnetometerData.magneticField`)
- **Тактильная отдача:** `UIImpactFeedbackGenerator`
- **Минимальная версия iOS:** 14.0+

## Структура проекта

```
MetalWireDetector/
├── MetalWireDetectorApp.swift   # Точка входа приложения (@main)
├── ContentView.swift            # Главный экран: индикатор, статус, кнопка
├── CircularGauge.swift          # Кастомный круглый индикатор
├── MagnetometerManager.swift    # Логика работы с магнитометром и калибровкой
└── Info.plist                   # Манифест приложения с разрешением на движение
```

## Логика работы

1. `MagnetometerManager` запускает обновления `CMMotionManager` с частотой 10 Гц.
2. Для каждого замера считается модуль вектора магнитного поля:

   ```
   |B| = sqrt(x² + y² + z²)   [μT]
   ```

3. Из значения вычитается калибровочное смещение (если пользователь нажал «Калибровка»).
4. По итоговому значению определяется статус:

   | Значение, μT | Статус                                    | Цвет     |
   | ------------ | ----------------------------------------- | -------- |
   | `< 70`       | Стена чиста / Металл не обнаружен         | зелёный  |
   | `70 – 120`   | Подозрение на металл/проводку             | жёлтый   |
   | `> 120`      | ВНИМАНИЕ! Обнаружен металл или кабель!    | красный  |

5. При превышении порога `100 μT` устройство вибрирует (с защитой от слишком частых срабатываний).

## ⚠️ Обязательная строка в `Info.plist`

Чтобы приложение получило доступ к датчикам движения (включая магнитометр), **необходимо** добавить ключ `NSMotionUsageDescription`:

```xml
<key>NSMotionUsageDescription</key>
<string>Приложению нужен доступ к датчикам движения, чтобы измерять магнитное поле и обнаруживать металл и электропроводку в стенах.</string>
```

Без этой строки iOS заблокирует доступ к CoreMotion, и магнитометр не будет работать.

## Запуск

> ⚠️ Запускать только на реальном устройстве iPhone — в iOS-симуляторе магнитометр недоступен.

1. Откройте проект в Xcode 14+.
2. Создайте новый iOS App-проект (SwiftUI, Swift) или импортируйте файлы из папки `MetalWireDetector/` в существующий проект.
3. Убедитесь, что в `Info.plist` присутствует `NSMotionUsageDescription` (см. выше).
4. Подключите iPhone и запустите приложение (`⌘ + R`).
5. При первом запуске iOS попросит разрешение на доступ к датчикам движения — нажмите «Разрешить».

## Использование

- Расположите телефон параллельно стене и медленно перемещайте его.
- Нажмите **«Калибровка»** возле «чистого» участка стены — приложение запомнит фон Земли и будет вычитать его из последующих замеров.
- Перемещая телефон по стене, следите за индикатором и цветом статуса.
- Сильное усиление поля (красный статус + вибрация) указывает на металл, арматуру или электропроводку под напряжением.

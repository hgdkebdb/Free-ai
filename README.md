# Metal & Wire Detector

Мобильное приложение для iOS на **Swift + SwiftUI**, использующее датчик магнитометра
(через **CoreMotion**) для обнаружения металла и электропроводки в стенах.

## Принцип работы

Приложение читает значения магнитного поля `(x, y, z)` с датчика магнитометра
и считает модуль вектора:

```
|B| = sqrt(x² + y² + z²)
```

Значение измеряется в микротеслах (μT).

- Естественный фон Земли: **30–60 μT**
- Превышение **100 μT** — близость металла или электромагнитного излучения

## Статусы

| Значение, μT | Статус | Цвет |
|---|---|---|
| `< 70` | Стена чиста / Металл не обнаружен | Зелёный |
| `70–120` | Подозрение на металл/проводку | Жёлтый |
| `> 120` | ВНИМАНИЕ! Обнаружен металл или кабель! | Красный |

При превышении порога **100 μT** срабатывает тактильная отдача
(`UIImpactFeedbackGenerator`).

## Калибровка

Кнопка **«Калибровка»** запоминает текущее фоновое значение `|B|`
и вычитает его из последующих замеров, чтобы компенсировать естественный фон Земли
или влияние окружающих предметов.

## Обязательная настройка `Info.plist`

Чтобы iOS разрешила приложению использовать датчики движения, в `Info.plist`
**обязательно** нужно добавить ключ `NSMotionUsageDescription`:

```xml
<key>NSMotionUsageDescription</key>
<string>Приложению нужен доступ к датчикам движения для измерения магнитного поля и обнаружения металла или электропроводки.</string>
```

Без этой строки система не даст приложению доступ к магнитометру, и `CMMotionManager`
не будет возвращать данные.

> В современных Xcode-проектах (со встроенным `Info.plist` в `project.pbxproj`)
> тот же ключ можно добавить через вкладку **Target → Info → Custom iOS Target Properties**,
> добавив запись `Privacy - Motion Usage Description`.

## Требования

- iOS 16.0+ (для `contentTransition(.numericText())`; на более ранних версиях можно убрать этот модификатор)
- Реальное устройство с магнитометром (на симуляторе датчик недоступен — приложение
  корректно покажет экран «Магнитометр недоступен»)

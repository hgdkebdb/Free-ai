# Metal & Wire Detector

iOS-приложение на SwiftUI для обнаружения металлических объектов **и проводов
под напряжением** с помощью встроенного магнитометра устройства (CoreMotion).

## Два режима работы

Приложение работает в двух режимах, переключаемых сегментированным контролом
в верхней части экрана:

### 1. Металл (DC — постоянная составляющая поля)

- Замеряется модуль вектора магнитного поля: `B = sqrt(x² + y² + z²)`, в μT.
- Нормальный фон Земли — 30–60 μT.
- Близость металла локально искажает фон → значение растёт.

| Значение, μT | Статус                                       | Цвет     |
|--------------|----------------------------------------------|----------|
| < 70         | Стена чиста / Металл не обнаружен            | Зелёный  |
| 70 – 120     | Подозрение на металл/проводку                | Жёлтый   |
| > 120        | ВНИМАНИЕ! Обнаружен металл или кабель!       | Красный  |

Калибровка в этом режиме «обнуляет» естественный фон Земли в текущей точке.

### 2. Провод 220В (AC — переменная составляющая поля)

- Переменный ток 50/60 Гц в проводе создаёт **колеблющееся** магнитное поле.
- Приложение опрашивает датчик с частотой 100 Гц и хранит скользящее окно
  из последних ~60 замеров (~0.6 с).
- Считает стандартное отклонение окна и умножает на √2 — это даёт оценку
  **амплитуды переменной составляющей** в μT.
- У постоянного поля разброс минимален → AC ≈ 0. Рядом с проводом под
  напряжением AC заметно растёт.

| Амплитуда AC, μT | Статус                                | Цвет     |
|------------------|---------------------------------------|----------|
| < 1.0            | Кабелей под напряжением не обнаружено | Зелёный  |
| 1.0 – 3.0        | Возможен провод под напряжением       | Жёлтый   |
| > 3.0            | ВНИМАНИЕ! Кабель под напряжением!     | Красный  |

Калибровка для этого режима не нужна и кнопка дезактивируется.

> **Важно:** провод под напряжением, но **без тока в нагрузке**, может почти
> не излучать переменное поле. Лучше всего обнаруживаются кабели, к которым
> подключён включённый прибор (лампа, чайник и т.п.).

## Тактильная отдача

`UIImpactFeedbackGenerator(style: .heavy)` срабатывает при превышении порога,
своего для каждого режима:
- Металл: > 100 μT;
- Провод: > 3 μT AC-амплитуды.

Чтобы не «трясти» постоянно, вибрация ограничена частотой ~3 раза в секунду.

## Структура проекта

- `MetalWireDetectorApp.swift` — точка входа (`@main`).
- `MagnetometerManager.swift` — работа с CoreMotion: чтение датчика на 100 Гц,
  расчёт DC- и AC-составляющих поля, калибровка, тактильная отдача.
- `ContentView.swift` — пользовательский интерфейс на SwiftUI: переключатель
  режимов, круговой индикатор, текстовый статус, кнопка калибровки.

## Info.plist

Для доступа к датчикам движения в `Info.plist` **обязательно** нужно добавить
ключ с описанием цели использования датчика:

```xml
<key>NSMotionUsageDescription</key>
<string>Приложению необходим доступ к датчикам движения для измерения магнитного поля и обнаружения металла.</string>
```

Без этой строки iOS не предоставит приложению доступ к магнитометру,
и пользователь не увидит запрос разрешения.

## Требования

- iOS 15.0+
- Устройство с магнитометром (большинство iPhone). На Симуляторе
  магнитометр недоступен — приложение покажет соответствующее сообщение.

# Metal & Wire Detector

Мобильное iOS-приложение на SwiftUI + CoreMotion для обнаружения металла и скрытой проводки с помощью магнитометра устройства.

## Структура проекта

```
MetalWireDetector/
├── MetalWireDetectorApp.swift   # Точка входа в приложение (@main)
├── ContentView.swift            # Главный экран: круглый индикатор, статус, кнопка калибровки
├── MagnetometerManager.swift    # Работа с CMMotionManager, расчёт поля, вибрация, калибровка
└── Info.plist.snippet.xml       # Сниппет с ключом, который нужно добавить в Info.plist
```

## Логика работы

- Считывание данных магнитометра через `CMMotionManager.startMagnetometerUpdates`.
- Расчёт суммарной силы поля: `sqrt(x² + y² + z²)` в микротеслах (μT).
- Базовый фон Земли ≈ 30–60 μT. Превышение 100 μT означает близость металла или ЭМ-излучения.

## Пороговые значения и UI

| Значение, μT | Цвет текста | Сообщение |
|---|---|---|
| < 70   | зелёный  | Стена чиста / Металл не обнаружен |
| 70–120 | жёлтый   | Подозрение на металл/проводку |
| > 120  | красный  | ВНИМАНИЕ! Обнаружен металл или кабель! |

- При превышении 100 μT срабатывает `UIImpactFeedbackGenerator(style: .heavy)` (вибрация).
- Кнопка **Калибровка** запоминает текущее значение как фоновое и вычитает его из последующих замеров.

## Info.plist — обязательная строка

В файл `Info.plist` нужно добавить ключ `NSMotionUsageDescription`, иначе iOS не выдаст разрешение на доступ к датчикам движения:

```xml
<key>NSMotionUsageDescription</key>
<string>Приложению нужен доступ к датчикам движения для определения магнитного поля и обнаружения металла или скрытой проводки.</string>
```

## Требования

- iOS 16+ (для `contentTransition(.numericText())`; на iOS 15 можно убрать этот модификатор).
- Реальное устройство с магнитометром — в симуляторе данных датчика не будет (`isMagnetometerAvailable == false`).
